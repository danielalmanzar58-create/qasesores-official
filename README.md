Sistema global de asesoría, control de operaciones monetarias y auditoría de departamentalización.

- **Roles Jerárquicos:** Supervisor (Diosaly) y Jefatura / Dirección General con panel de movimientos exclusivo.
- **Bitácora de Auditoría de Movimientos:** Trazabilidad completa de modificaciones.
- **KPIs y Métricas Operativas:** Control de tiempos y estados en tiempo real.
- **Diseño Corporativo Neón & Cyber-Executive:** Interfaz de alto standing.
- **Exportación a Excel y Adaptabilidad Móvil / PC.**
